# Workflow Console UI Prototype

Throwaway prototype for comparing three Termux-integrated Workflow Console layouts.

Run with one command:

```bash
open "file:///Users/dwolf/devhub/projects/termux-app/repo/app/prototypes/workflow-console/index.html?variant=A"
```

Use the floating switcher or the left and right arrow keys to compare variants A, B, and C.

This prototype uses in-memory sample data and must not be promoted directly into production code.
